# DomainDrivenDesign

Assess whether Domain-Driven Design is appropriate, model business boundaries, and guide strategic, tactical, and event-driven architecture decisions.

## What this skill covers

- Practical guidance for domain driven design workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill for tasks related to domain driven design. Provide the relevant context, constraints, and expected outcome. Review generated changes before applying them.
